Part 1: 3-to-8 Decoder

Inputs: A (MSB), B, C (LSB). Outputs: Y0–Y7 (exactly one HIGH at a time).

Architecture

Since you don't have AND3, use a partial-product tree of AND2 gates:

            STAGE 1 (1 tick)       STAGE 2 (2 ticks)        STAGE 3 (2 ticks)
            3× NOT                 4× AND2                   8× AND2

    A ──┬──►[NOT]──► A̅ ──┬──►[AND2]── A̅B̅ ──┬──►[AND2 w/ C̅]──► Y0 (=A̅B̅C̅)
        │                 │                  └──►[AND2 w/ C ]──► Y1 (=A̅B̅C)
        │                 │
        │            B̅ ──┤──►[AND2]── A̅B  ──┬──►[AND2 w/ C̅]──► Y2 (=A̅BC̅)
        │                 │                  └──►[AND2 w/ C ]──► Y3 (=A̅BC)
        │                 │
        ├─────────────────┤
        │                 │
    B ──┼──►[NOT]──► B̅   │
        │                 │
        ├─────────────┬───┘
        │             │
        │        A ───┤──►[AND2]── AB̅  ──┬──►[AND2 w/ C̅]──► Y4 (=AB̅C̅)
        │             │                  └──►[AND2 w/ C ]──► Y5 (=AB̅C)
        │             │
        │             └──►[AND2]── AB   ──┬──►[AND2 w/ C̅]──► Y6 (=ABC̅)
        │                                └──►[AND2 w/ C ]──► Y7 (=ABC)
        │
    C ──┴──►[NOT]──► C̅

Gate count: 3 NOT + 4 AND2 + 8 AND2 = 15 gates

Critical path: NOT(1) + AND2(2) + AND2(2) = 5 ticks

The complement trick

Since exactly one Yi is HIGH at a time, instead of OR-ing the many ON digits, we can NOR the few OFF digits — whichever set is smaller:

┌─────────┬────────────────┬───────────────┬───────────────┐
│ Segment │ OFF for digits │ ON for digits │ Best approach │
├─────────┼────────────────┼───────────────┼───────────────┤
│ a       │ 1, 4           │ 0,2,3,5,6,7   │ NOR the 2 OFF │
├─────────┼────────────────┼───────────────┼───────────────┤
│ b       │ 5, 6           │ 0,1,2,3,4,7   │ NOR the 2 OFF │
├─────────┼────────────────┼───────────────┼───────────────┤
│ c       │ 2              │ 0,1,3,4,5,6,7 │ NOT the 1 OFF │
├─────────┼────────────────┼───────────────┼───────────────┤
│ d       │ 1, 4, 7        │ 0,2,3,5,6     │ NOR the 3 OFF │
├─────────┼────────────────┼───────────────┼───────────────┤
│ e       │ 1,3,4,5,7      │ 0, 2, 6       │ OR the 3 ON   │
├─────────┼────────────────┼───────────────┼───────────────┤
│ f       │ 1, 2, 3, 7     │ 0,4,5,6       │ NOR the 4 OFF │
├─────────┼────────────────┼───────────────┼───────────────┤
│ g       │ 0, 1, 7        │ 2,3,4,5,6     │ NOR the 3 OFF │
└─────────┴────────────────┴───────────────┴───────────────┘

Segment equations and delays

    a = NOR2(Y1, Y4)                                          → 1 tick

    b = NOR2(Y5, Y6)                                          → 1 tick

    c = NOT(Y2)                                                → 1 tick

    d = NOR2( OR2(Y1, Y4), Y7 )                               → 3 ticks
            └── 2 ticks ──┘  └ 1 tick after OR2 ready ┘

    e = OR2( OR2(Y0, Y2), Y6 )                                → 4 ticks
            └── 2 ticks ──┘  └ 2 ticks after first OR2 ┘

    f = NOR4(Y1, Y2, Y3, Y7)                                  → 2 ticks

    g = NOR2( OR2(Y0, Y1), Y7 )                               → 3 ticks
            └── 2 ticks ──┘  └ 1 tick after OR2 ready ┘
