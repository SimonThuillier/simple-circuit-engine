component: eightBitOnesComplement

state:
Following the validated convention for upper level components (more than one logic output) states correspond to the outputs expressed in hexadecimal.
in the case of 8 bits one's complement it would be one extra bit for the invert flag input plus the 8 bits of the output
Hence a 2 hexa characters representation ranging from 00 to 1F

Guards:
vcc guard: if pin vcc has not voltage a vcc guard clause like in LogicGateBehaviorMixin should bring the state to '0000' immediately
nonLogicInputGuard: if any logicInput pin is nonlogical a nonLogicInputGuard like in LogicGateBehaviorMixin should bring the state to 'indeterminate' immediately.

Transitions :
to handle transient state the formula beneath is proposed :
`to${nextState}`

the full list of states would then be :
['000' ....'1FF', 'indeterminate']

events:
Following the convention proposed above and to avoid hardCoding all possible transitions events name will be computed with the formula :
`to${nextState}`

the state and nextState in the behavior result will be the primary source of information for animations.
For animations needs the state previous the currentOne can be saved as state parameter prevState (convention introduced for half-adder).

behavior:
Behavior will be quite straightforward.
For behavior a change in one of the 8 inputs at invert constant will produce the natural xor transition at this position.
Example
- at t=0 invert/input 1/80, state 17F
- at t=1 invert/input changes to 1/00, states goes to1FF and an event to1FF is emitted (optionally it can indicate in its name or a parameters that its due or not to a change of invert)
- at t=4 event resolves and state is set at 1FF

- at t=11 invert changes to 0 with input constant at 00 , state goes to000 and event to000 is emitted
- at t=14 event resolves and state is set at 000

The span used can use the symmetrical simplification pattern :
`
const transitionSpan = getTransitionSpan(component.config);
    const span =
      state.expirationTick < 1 ? transitionSpan : Math.max(targetTick - state.startTick, 1);
`



Handling concurrent events :
the salt of big components : handling multiple events happening concurrently.
Here the edge case is handling smoothly what happens when one or more inputs change just after invert has changed.
